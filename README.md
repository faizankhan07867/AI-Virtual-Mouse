# AI-Virtual-Mouse

# 🖱️ AI Virtual Mouse using OpenCV & MediaPipe

## 📌 Overview

AI Virtual Mouse is a Computer Vision project that enables users to control the computer mouse using hand gestures. The project uses OpenCV for video processing, MediaPipe for hand tracking, and PyAutoGUI for controlling mouse movements and click actions in real time.

---

## ✨ Features

- 🖱️ Virtual Mouse Control
- ✋ Real-Time Hand Tracking
- 👆 Left Click Gesture
- 👉 Right Click Gesture
- 📜 Scroll Up & Down
- 📷 Live Webcam Support
- ⚡ Smooth Cursor Movement
- 🤖 MediaPipe Hand Detection

---
